# VS Code で学ぶ Git / GitHub 実践課題

このリポジトリは、**VS Code に組み込まれている Git 機能**を使って、Git と GitHub の基本操作をひと通り体験するための課題です。
プログラミングの知識は必要ありません。扱うのは文章（Markdown）ファイルだけです。

> [!IMPORTANT]
> **「Use this template」で自分のリポジトリを作るときは、必ず「Include all branches」にチェックを入れてください。**
> チェックを忘れると、Mission 7 で使う `practice/conflict` ブランチがコピーされません。
> （忘れた場合は、`MISSIONS.md` の最後にある「付録」の手順で自分で用意できます）

---

## 全体の流れ

```
STEP 0  事前準備             VS Code・Git のインストール、名前の登録        （自分の PC）
   ↓
STEP 1  自分用リポジトリ作成  このリポジトリをテンプレートにしてコピー       （ブラウザ）
   ↓
STEP 2  サインイン＆クローン  VS Code で GitHub にログインして手元に取り込む （VS Code）
   ↓
STEP 3  ミッション 1〜8       MISSIONS.md の手順どおりに進める               （VS Code）
```

**STEP 3 からは基本的に VS Code だけで進めます。** ブラウザを使うのは、Mission 5 のプルリクエスト作成と、「GitHub に反映されたか」を確かめるときだけです。

## この課題で学ぶこと

### まず覚える「4 つの場所」

Git の操作は、変更が次の 4 つの場所を移動していくだけです。

```
① 作業中のファイル  →  ② ステージ   →  ③ 自分の PC の履歴  →  ④ GitHub
   （保存した状態）      （＋ボタン）      （コミット）            （プッシュ／同期）

                                           ③ 自分の PC の履歴  ←  ④ GitHub
                                                                  （プル）
```

各ミッションは、「どの場所で、どんな操作をするのか」を 1 つずつ体験できるように並んでいます。

### ミッションの構成

| ステージ | ミッション | 体験すること | わかるようになること |
| --- | --- | --- | --- |
| **1. 基本の流れ** | Mission 1 | コミット＆プッシュ | ①→②→③→④ を一周して、GitHub に反映される |
| | Mission 2 | 変更の破棄（Discard） | ① の段階なら、変更をなかったことにできる |
| **2. ブランチ** | Mission 3 | ブランチの作成と切り替え | ブランチを切り替えるとファイルが消えたり復活したりする＝「並行世界」 |
| | Mission 4 | ローカルでのマージ | 並行世界の変更を `main` に合流させる |
| **3. チーム開発** | Mission 5 | プルリクエスト（PR）とプル | ブランチ → PR → GitHub でマージ → 手元に**プル**（④→③）という実務の流れ |
| **4. トラブル対処** | Mission 6 | コミットの取り消し（Revert） | プッシュ済みの間違いを、履歴を壊さず打ち消す |
| | Mission 7 | マージコンフリクトの解消 | 同じ行がぶつかったとき、どちらを残すか自分で選ぶ |
| | Mission 8 | `.gitignore` で機密情報を守る | API キーなどを GitHub に上げない方法 |

## STEP 0：事前準備

### 1. ツールをインストールする

1. **VS Code** … https://code.visualstudio.com/ からインストール
   - 日本語で使いたい場合は、拡張機能「Japanese Language Pack for Visual Studio Code」を入れて VS Code を再起動します。
2. **Git** … https://git-scm.com/ からインストール（Windows はインストーラーの設定をすべて初期値のままで OK）
3. **GitHub アカウント** … https://github.com/ で無料登録

### 2. Git に名前とメールアドレスを登録する（最初の 1 回だけ）

コミットには「誰が変更したか」が記録されます。その記録に使う名前を登録します。

VS Code を開き、メニューの **ターミナル → 新しいターミナル（Terminal → New Terminal）** で画面下にターミナルを出し、次の 2 行を 1 行ずつ貼り付けて Enter を押します（`あなたの名前` などは自分のものに置き換えてください）。

```
git config --global user.name "あなたの名前"
git config --global user.email "GitHubに登録したメールアドレス"
```

> 📝 これは「コミットに記録する名前」の登録で、**GitHub へのログインとは別物**です。ログインは STEP 2 で行います。

## STEP 1：自分用のリポジトリを作る（ブラウザ）

1. ブラウザで GitHub にログインし、このリポジトリのページを開きます。
2. 右上の緑色のボタン **「Use this template」→「Create a new repository」** をクリックします。
3. 次のように設定します。
   - ⚠️ **Include all branches（すべてのブランチを含める）に必ずチェックを入れる**
     - 初期状態ではチェックが**外れています**。ここを忘れると Mission 7 で使う `practice/conflict` ブランチがコピーされません。
   - Repository name: 好きな名前（例: `my-git-practice`）
   - 公開範囲: **Private** を選ぶ
4. **「Create repository」** をクリックします。

> これで「あなた専用のコピー」が GitHub 上にできました。以降はこのコピーで自由に練習してください。他の人の作業とぶつかることはありません。

---

## STEP 2：VS Code で GitHub にサインインしてクローンする

STEP 1 で作ったリポジトリは **Private（非公開）** なので、VS Code から GitHub に**ログイン（サインイン）**しないと取り込めません。クローンの途中でサインインする流れになっています。

1. VS Code を開き、`Ctrl + Shift + P`（Mac は `Cmd + Shift + P`）でコマンドパレットを開きます。
2. `Git: クローン`（`Git: Clone`）と入力して選びます。
3. 表示された候補から **「GitHub から複製」**（Clone from GitHub）を選びます。
4. **GitHub へのサインイン**を求められます。
   1. 「拡張機能 'GitHub' が GitHub を使用してサインインしようとしています」と出たら **「許可」**（Allow）を押します。
   2. ブラウザが開くので、GitHub にログインし、**「Authorize Visual Studio Code」** などの緑のボタンで許可します。
   3. 「Visual Studio Code を開きますか？」と聞かれたら **「開く」** を押して VS Code に戻ります。
5. VS Code に自分のリポジトリの一覧が出るので、STEP 1 で作ったリポジトリ（例: `あなたのID/my-git-practice`）を選びます。
6. 保存先のフォルダーを選ぶと、クローンが始まります。
7. 右下に「クローンしたリポジトリを開きますか？」と出たら **「開く（Open）」** を押します。
   - 「このフォルダー内のファイルの作成者を信頼しますか？」と出たら **「はい、作成者を信頼します」** を選びます。

左側のエクスプローラーに `README.md` や `MISSIONS.md` が表示されていれば成功です。

> 💡 **サインインできたか確かめるには**：VS Code の左下にある人型のアイコン（アカウント）をクリックすると、サインイン中の GitHub アカウント名が表示されます。
>
> 💡 **「GitHub から複製」が出ない場合**：自分のリポジトリのページで緑の **「Code」** ボタンから URL（`https://github.com/...git`）をコピーし、手順 3 で URL を貼り付けて Enter を押してください。「Git Credential Manager」という小さな画面が出たら **「Sign in with your browser」** を選び、ブラウザでログインします。

---

## STEP 3：ミッションを進める（VS Code）

1. VS Code のエクスプローラーで **[`MISSIONS.md`](MISSIONS.md)** を開きます。
2. `Ctrl + K` を押してから `V` を押す（Mac は `Cmd + K` → `V`）と、手順書の**プレビューが右側に**表示されます。
   - 左で作業しながら、右で手順を読めるので便利です。
3. Mission 1 から順番に進めてください。

### 進め方のコツ

- **各ミッションの最後の「✅ 確認ポイント」を必ず確かめる**
  変更が「4 つの場所」のどこまで届いたかを見るのが、いちばんの学びになります。
- **ソース管理の「グラフ」（Graph）を時々見る**
  Mission 3〜7 では、履歴の線が枝分かれしたり合流したりする様子が見えます。
- **詰まったら `MISSIONS.md` の「困ったときは」を見る**
- **最後のチェックリストがすべて埋まったら修了です**
